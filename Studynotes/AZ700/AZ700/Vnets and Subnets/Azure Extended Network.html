Azure Extended Network

//allows on-premises VMs to migrate to Azure without changing their IP addresses. 

Prereq: S2S VPN or ExpressRoute (Layer 3 pipe)
Subnets: VNet has GatewaySubnet + Target Subnet (match On-Prem CIDR)

[onPrem¹] ➔ [NIC⁸] (L2 Extension)
[onPrem¹][Az. Extended Nw⁷] ➔ [WAC VM Appliance¹¹] ➔ [WAC Extension¹²] ➔ [VpnGw¹¹ | ErGw¹¹] ➔ [NIC⁸]
 

Use Windows Admin Center to configure the server onprem and in azure and orchestrate.

Routing: Azure WAC VM acts as the "Next Hop" for the stretched subnet.
Limit: Only for Windows Server workloads (2012 R2+).
Dependency: If the WAC Extension is deleted, the L2 bridge breaks.

Hardware: Azure WAC VM requiresNested Virtualization (Dv3/Ev3 series or newer).
MAC Spoofing: Must be Enabled on theAzure VM NIC to allow the same IP address.
