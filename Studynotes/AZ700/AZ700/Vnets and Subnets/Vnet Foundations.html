Vnet Foundations

Magic IP: 168.63.129.16
Trigger: DHCP, DNS, & LB Health Probes.
Hard-Lock: Never block in NSG. Blocking = Backend Offline.
 
IP Reservations (Subnet)
First 4: .0 (Net) | .1(GW) | .2/.3 (DNS)
Last 1: .255 (Broadcast)
Hard-Lock: Cannot assign these to any resource.
 
BGP / ASN (Routing)
ASN 12076: Microsoft Public/Private/Microsoft Peering (ExpressRoute).
ASN 65515: Mandatory for VPN/ER Coexistence & Default VNet ASN.
Reserved ASNs (Internal): 8074, 8075, 65517-65520. //Never use these for On-Prem BGP.
Ports
TCP 53 / UDP 53: DNS resolution via Magic IP.
TCP 32526: WireServer Port (VM Agent ↔ Platform).
