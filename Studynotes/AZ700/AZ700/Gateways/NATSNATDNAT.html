INSTANT DECISIONS

"Need outbound access for a private backend pool" ➔ Add a NAT Gateway to that subnet.
"LB SNAT ports are full" ➔ Migrate to NAT Gateway (On-demand allocation).
"Fixed IP range for customer whitelist" ➔ Associate Public IP Prefix to NAT Gateway.
"Outbound traffic shows wrong IP" ➔ NAT Gateway overrides Instance-level Public IPs.
"New VM cannot reach the internet" ➔ Must associate a NAT Gateway to the subnet.
