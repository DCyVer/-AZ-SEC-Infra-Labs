! EXAM ! 
"Tunnel won't connect due to matching IP ranges" ➔ Must use VPN NAT rules.
"Send all Azure VM internet traffic to On-Prem" ➔ Enable Forced Tunneling via UDR on GatewaySubnet.
"Need to inspect Gateway traffic with a Firewall" ➔ Disable Fastpath. ( ! NSG /UDR bypass ! )
 "On-prem BGP peer cannot reach Azure" ➔ Check if APIPA(/169.254.21+22.0/24) BGP IP is configured. /
"Spoke VNet needs to use Hub VPN Gateway" ➔ Must use VpnGw1 or higher.
"VPN Client 403 Forbidden" ➔ Correct Audience ID (Azure VPN App ID).
"Inspect VPN traffic with Azure Firewall" ➔ Disable Fastpath + Add UDR to GatewaySubnet.
"MFA for Linux/Mac/Windows" ➔ OpenVPN + Entra ID Auth.
