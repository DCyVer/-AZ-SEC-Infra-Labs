BYOIP

Hard-Locks (2026)

  • IPv4 Min Size: /24 (Exactly).

  • IPv6 Min Size: /48 (Global) | Child ranges regularly /64, but /48 allowed (2026)

  • SKU: Results in Standard SKU Public IPs only.

  • Proof: Requires ROA (Route Origin Authorization) to prove ownership.

  • ASN: Must be 8075 (Public) or 8070 (US Gov Cloud).

  • State Dependency: Prefix must be in the Commissioned state before Public IP addresses can be carved from it for use.Operational Flow

  1. Validation: ROA + Signed Message.

  2. Provision: Range appears in Azure.

  3. Commission: Azure begins advertising the range to the Internet.

 
🎯 INSTANT "NO" TRIGGERS

  • "Bring a /25 or /28 range" ➔ NO (Min is /24).

  • "Use with Basic Load Balancer" ➔ NO (Standard SKU only).

  • "Stretch one /24 across 2 regions" ➔ NO (Regional resource only).
