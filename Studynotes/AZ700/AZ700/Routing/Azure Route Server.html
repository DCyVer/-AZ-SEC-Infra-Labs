Azure Route Server

INSTANT DECISIONS
"Dynamically update routes for 50 Spoke VNets without 50 UDRs" ➔ Azure Route Server.
"NVA is peering but VMs aren't seeing routes" ➔ Check "Use Remote Gateway/Route Server" on the Peering config.
"Route Server vs. ExpressRoute Gateway" ➔ ARS is not a Gateway; it only exchanges Route Info, not the actual data packets.


BGP Peering: Acts as a BGP speaker to exchange routes with a Network Virtual Appliance (NVA) 
Route Injection: Auto Update "Effective Routes" of all VMs in the VNet (Include: Use Remote Gw/Routeserver; Exclude UDR) 

max 8 BGP peers /ARS  
Subnet: Dedicated RouteServerSubnet | Min /27.
// BGP-injected routes never override UDR
