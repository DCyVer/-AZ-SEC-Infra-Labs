SaaS (Mged IP/ PaaS (Svc./Priv. Endpts) and Private Link

 (INSTANT DECISIONS)

  • "Access Azure SQL from On-Premises" ➔ Private Link (Endpoint).

  • "Block access to all Storage except Prod-Account" ➔ Service Endpoint + EP Policy.

  • "Minimize cost for VNet-only traffic" ➔ Service Endpoint ($0).

  • "Use NSG to filter traffic to a PaaS service" ➔ Private Link (with NIC Policy).

 

Service Endpoint | Public IP | $0
vNet (Enable on subnet → routing) → Azure Backbone(Bypass UDR) → PaaS(Virtual Network Rule: Allow Subnet ID)
EP Policy: Anti-Exfiltration → Limit access to specific resource ID.
Excludes:  Hybrid Access (VPN/ER).

Private Link (Endpoint) | Private IP | $Cost

Assigns a Private IP from your VNet. to connect On-Prem (VPN/ER) and Peered VNets.
Uses: Private DNS Zone + vNet Link for resolution.
Identity needs Network Contributor role on thePrivate DNS Zone (Hub) to auto-sync A-records
Exception: Must enable PrivateEndpointNetworkPolicies for NSG/UDR support.

Service Tags | Managed IP | $0
IP-Group:   multiple IP set for service-specific NSG rules (e.g. Storage.EastUS). // No FQDN
 
FQDN Filtering | Domain Name | $Cost
{App-Rules} = Az Fw ; filtering by *.microsoft.com. for (Microsoft 365 / Windows Update / GitHub traffic) 
{Web-Categories} = Filter content (e.g. Social, Hacking, gambling).
