Hybrid & DNS

  • DNS Resolver: Confused Inbound (On-prem to Azure) with Outbound (Azure to On-prem).

  • DNS Peering: Incorrectly assumed peering automatically shares Private DNS Zone links.

  • SSTP Protocol: Missed that SSTP = P2S VPN, not Azure Bastion.

  • BGP Path: Missed AS Path Prepending as the primary tool for Primary/Backup path selection.

 
2. Load Balancing (L4 vs. L7)

  • Proxy Traffic: Tried to use L4 (Standard LB) for users behind a single proxy; requires L7 (App Gateway) for cookie-based affinity.

  • HA Ports: Missed HA Ports as the requirement for NVA/Firewall load balancing.

     

 
3. IP & Routing

  • BYOIP: Confused Custom IP Prefix (Public/Internet) with VNet Address Space (Internal/NIC).

  • Forwarded Traffic: Over-applied "Allow Forwarded Traffic" to direct VNet-to-VNet peering (it is for Transit only).

  • Firewall Subnet: Incorrectly chose /29; the minimum requirement is /26.

 
4. SKUs & Limits

  • VPN Thresholds: Missed the 1,000-connection limit for VpnGw2 .

  • Resiliency: Missed that "surviving datacenter failure" requires the -AZ SKU suffix.

  • vWAN SKU: Missed that Basic vWAN does not support ExpressRoute or P2S.

 
5. Security & Monitoring

  • Exfiltration: Missed Service Endpoint Policies for restricting access to specific storage accounts.

  • MAC Addresses: Chose NSG Flow Logs (L3/4) instead of VNet Flow Logs (L2/MAC).
