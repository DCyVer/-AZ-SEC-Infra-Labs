Network Access: Security & Identity

SECURITY & IDENTITY STACK (2026)
Front Door (WAF) ➔ HTTPS (Global L7) | WAF Policy | Global acceleration + SQLi/XSS Edge protection
App Gateway (WAF) ➔ HTTPS (Regional L7) | WAF Policy | URL-path routing + Regional WAF
Firewall (Premium) ➔ L3-L7 | IDPS/TLS Signature | Signature-based IDPS / FQDN filtering
P2S (OpenVPN) ➔ SSL/TLS | Entra ID | Conditional Access / Modern Auth //Firewall-friendly
P2S (IKEv2) ➔ IPsec | Cert/RADIUS | Native Mobile Support (No 3rd party client)
P2S (SSTP) ➔ SSL (TCP 443) | Cert/RADIUS | Legacy Windows 443 bypass
NSG / ASG ➔ TCP/UDP | Service Tags | Micro-segmentation / Filter between subnets
 
 
🔑 AUTH & PROTOCOL MATRIX
Kerberos ➔ Dev/Std Bastion | Entra Domain Services //Legacy auth on VNet (No DC VMs)
mTLS (Mutual TLS) ➔ App Gateway v2 | Front Door Prem //Verify Client Identity at the WAF
RADIUS ➔ P2S (IKEv2/SSTP) | VPN Gateway //Connects to On-Prem NPS for auth
Certs (Self-Signed/CA) ➔ P2S (IKEv2/SSTP) | App Gateway //End-to-end SSL/TLS
FIDO2 / Passwordless ➔ P2S (OpenVPN + Entra ID) //Requires Modern Auth via Conditional Access
BGP Password ➔ ExpressRoute / VPN Gateway //MD5 Hash auth for BGP peering
 
 
🔍 2026 IDENTITY “HARD-LOCKS”MACsec (802.1AE) ➔ ExpressRoute Direct | Encryption at Layer 2 (Link layer)
PIM ➔ Just-In-Time (JIT) access for Azure Roles (e.g., Network Contributor)
JIT (VM Access) ➔ Microsoft Defender for Cloud | Dynamic NSG port opening (3389/22)
TLS Inspection ➔ Azure Firewall Premium | Required for IDPS on encrypted payloads
Double Encryption ➔ ExpressRoute + IPsec | Required for high-compliance (L2 + L3 encryption)
Bastion Shareable Links ➔ Access VMs via URL without Entra ID/Azure account
 
 
🎯 DETERMINISTIC AUDIT (EXAM TRIGGERS)

  • "SQLi protection for Global site" ➔ Front Door (WAF)

  • "Legacy LDAP / Kerberos support" ➔ Entra Domain Services

  • "Block specific URLs in VNet" ➔ Azure Firewall (App Rules)

  • "Encrypt ExpressRoute at Layer 2" ➔ MACsec

  • "Encrypt ExpressRoute at Layer 3" ➔ IPsec (VPN over ER)

  • "Temp RDP access to VM" ➔ JIT (VM Access)

  • "Network Admin role for 2 hours" ➔ PIM

  • "Authenticate VNet users via On-Prem NPS" ➔ RADIUS

 

  • P2S Protocol limit: Remember SSTP is Windows-only. If the scenario says "Mac/Linux/Windows" and "TCP 443," the answer is OpenVPN, not SSTP.

  • WAF tiers: Front Door WAF is always "Global/Edge" (Static + Dynamic); App Gateway WAF is "Regional" (Dynamic/VNet-bound).
