{Evaluation Law} = Custom Rules (Priority) ➔ Managed Rulesets (DRS 2.1).
{Evaluation Law} = Evaluated by Priority (Lower # wins); stops on first match.
 
DIAGNOSTICS & THE "X-FORWARDED-FOR" GAP
{Source IP} = Backend sees Front Door Edge IP or App Gateway IP.
{Real Client IP} = Contained in X-Forwarded-For header.
{Fix} = Application must be configured to read the header for logging/security.

KILL-SWITCH: THE FALSE POSITIVE FIX
{Legit Traffic Blocked} = Valid cookie/string flagged as attack (403 Forbidden). - > {Fix} = WAF Exclusion Rule.
→ {Method} = Extract Rule ID from Diagnostic Logs (Firewall Logs) ➔ Add to Exclusions.
