FW Rule = 1st 2 match in priority order only. 

  1. DNAT = [IN B4 OUT ]  / ext- to int. IP translation

  2. Network [OSI 3/4]  / filters by IP/Port/Protocol.

  3. Application [OSI 7] / filters by FQDN or Web Categories.

  4. Deny by default*

    * Exception: Azure Firewall allows internal platform traffic by default. (2nd lowest prio)  
     

Azure Firewall Policy Hierarchy

  • Inheritance: Child policies inherit all rules from a Parent policy [5].

  • Processing Order: Parent rules always evaluate before Child rules [5].

  • Rule Conflict: A "Deny" in a Parent policy cannot be overridden by an "Allow" in a Child policy [5].

  • Priority Numbers: Lower numerical values (e.g., 100) have higher priority and process before higher values (e.g., 1000) [6].

 

FQDNs: Application Rules only. Network Rules do not support FQDNs.
DNS Proxy: Mandatory for FQDN filtering to prevent IP spoofing/mismatch.
