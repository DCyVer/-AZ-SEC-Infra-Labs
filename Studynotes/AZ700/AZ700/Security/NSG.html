3. THE DEFAULT NSG GATE (THE INVISIBLE RULES)
Every Network Security Group has "Hidden" rules with priority 65000+. You can't delete them, but you can override them with any rule numbered 100-4096.  
+ Priority 65000 (Inbound) ➔ Allow VNet ➔ Any-to-Any (Internal)
+ Priority 65001 (Inbound) ➔ Allow Azure Load Balancer ➔ Health Probes
+ Priority 65500 (Inbound) ➔ Deny All ➔ The "Wall"
+ Priority 65001 (Outbound) ➔ Allow Internet ➔ Egress Access
EXAM TRAP ➔ If you place an NSG on a subnet and want to block all internal communication, you must create a manual Deny rule at a lower priority (e.g., 1000) to override the 65000 "Allow VNet" default.
