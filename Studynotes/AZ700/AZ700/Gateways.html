Gateway Precedence 

  1. DNS Resolution (Local Hosts ➔ DNS Proxy (Firewall) ➔ Private DNS Resolver ➔ Private DNS Zone ➔ Public DNS.)

  2. User-Defined Routes (UDR): // Static Wins: Manual routes (::/0 to NVA) override all BGP and System routes.)

  3. BGP (Longest Prefix Match - LPM): //specific /24 from VPN beats a general /16 from ExpressRoute

  4. ExpressRoute (ER) // if both same prefix (/24), ExpressRoute > VPN.

  5. VPN Gateway: //Fallback for cross-prem if no ER exists.

  6. Outbound Internet Exit (The "SNAT" Gate) → NAT Gateway ➔ Instance-level PIP ➔ Standard Load Balancer.

    • //NAT Gateway always overrides the others for internet-bound traffic.
