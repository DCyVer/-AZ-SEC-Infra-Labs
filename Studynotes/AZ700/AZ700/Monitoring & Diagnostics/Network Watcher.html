- Network Watcher Tools → Regional Service enablement  (Default on Vnet deployment, else manually enable in target Vnet region) 
 
Next Hop | Source: NIC | Returns: Hop Type
Trigger: Verify Routing | UDR issues | Identify NVA path
{VirtualAppliance} = NVA/Firewall (UDR)
{Internet} = System Route (0.0.0.0/0)
{None} = Dropped @ NIC //No valid route
 
IP Flow Verify: Check NSG Allow/Deny //5-tuple match
Trigger: Security Rules | Traffic Filtering | Confirm Port Access
 
Packet Capture | Payload Analysis | Req: Storage Account
Trigger: Deep Packet Inspection (DPI) | Protocol Failure (TLS/SSL)
{TCP Retransmissions} = Loss at 1500 in ER/VPN → MTU/MSS 1350/1400 to compensate for 10% overhead (Encapsulation) 
{Zero Traffic} = Check Next Hop (Routing) or IP Flow (NSG)

 PERFORMANCE (Connection Monitor)

{<100ms + Loss}: NIC/VM Saturation → Upsize VM SKU

  • V1 | Basic flow | Captures ingress/egress IP traffic (Allowed/Denied).

  • V2 | + Bytes | Packets | Enhanced Flow State (Open/Active/Closed) → Throughput Analysis.

Audit paths: 

  • {Flow Allowed: High Volume} = Data Exfiltration → Check Application Layer/DLP.

  • {Flow Denied: High Frequency} = Port Scan/Recon → Block Source IP via NSG or Firewall.

  • {Encryption: False} = Internal Exposure → Enable VNet Encryption (2026 Objective). //vCPU floor (dV4, eV4)

  • {Malicious IP Source} = Threat Intelligence Match → View via Traffic Analytics (LAW).
