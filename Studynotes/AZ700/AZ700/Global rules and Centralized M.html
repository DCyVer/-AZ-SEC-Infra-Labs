TAGS VS. GROUPS
- Service Tags ➔ IP-based filtering for Azure Services (NSG or Firewall).
- FQDN Tags ➔ Pre-defined category filtering (e.g. WindowsUpdate) in Application Rules ONLY.
- IP Groups ➔ Reusable IP collections for multiple Firewall/NSG rules.

Service Tags vs. IP Groups: Filtering by Azure Service (Identity) vs. a reusable list of custom IPs.
Application Rule (Target FQDN tags) vs. Network Rule (using FQDNs)
ASG (Application Security Groups): Grouping VMs by role (Web/DB) to simplify NSG rules.

[FRONT DOOR]

- Verify Edge Cache ➔ X-Cache Header (TCP_HIT) | File Compression ➔ Brotli/Gzip (1KB–8MB)

Security:

- Country-block ➔ Geomatch | Request volume cap ➔ Rate Limit
- Hide backend tech ➔ Strip X-Powered-By | Origin Bypass Check ➔ [X-Azure-FDID]
- OWASP/Exploits ➔ Managed Rules | Scrapers/Crawlers ➔ Bot Manager
- Zero-Public IP backend ➔ Premium SKU (Private Link) | Audit vs. Block ➔ WAF Mode
 

[TRAFFIC MANAGER]

- Non-HTTP / Gaming / Any Protocol ➔ DNS-based Routing | Lowest Cost ➔ Traffic Manager
- See original Client IP at backend ➔ Direct Connection (No Proxy)
- Failover delay (30s–300s) ➔ DNS TTL | List of healthy IPs ➔ MultiValue
- Corporate-only IP mapping ➔ Subnet Routing | Multi-stage logic (Geo ➔ Priority) ➔ Nested Profiles

Security:

- No Packet Inspection ➔ L4 Passthrough | Inherits Azure DNS DDoS protection
- No WAF/SSL Offload ➔ Backend must handle Security/Certificates


[APP GATEWAY]
- URL segment (/images) ➔ URL Path Map | Host Headers (contoso.com) ➔ Multisite Listener
- Modify Header / URL on-the-fly ➔ Rewrite Rule | Assign WAF to specific Listener ➔ Regional Policy
- Health check specific path (/health) ➔ Custom Probe | Enforce TLS versions ➔ SSL Policy
- Session Persistence: Enable Cookie-based Affinity.
- Zero-Downtime Maintenance: Enable Connection Draining.

Security: 
- Hide backend tech ➔ Rewrite Rule (Strip X-Powered-By) | Audit vs. Active Block ➔ WAF Mode (Detection vs. Prevention)
- Decrypt at Gateway / Plaintext to Backend ➔ SSL Termination
- mTLS (Mutual TLS): Assign SSL Profile (Client Certificate Auth) to Listener.
- TLS 1.0/1.1 is Retired. SSL Policy must enforce TLS 1.2+.
- Zero-Public IP backend ➔ Private Link (Standard V2)

IP RESERVATIONS & MAGIC IPs
Azure always steals five IP addresses from every subnet. If you see a /29 (8 IPs), only 3 are usable. 

Smallest Gateway / AzureRouteServerSubnet Subnet ➔ /27 (32 IPs total | 27 Usable)

+ x.x.x.0 ➔ Network Address
+ x.x.x.1 ➔ Default Gateway
+ x.x.x.2 ➔ Azure DNS (Mapping)
+ x.x.x.3 ➔ Azure DNS (Redundancy)
+ x.x.x.255 ➔ Broadcast Address (Reserved, not used)
+ 168.63.129.16 ➔ "Magic IP" // WireServer (DNS, DHCP, LB Health Probes, VM Agent)
+ 169.254.169.254 ➔ IMDS (Instance Metadata Service - SKU, Region, Auth)
// This IP is non-routable. It cannot be reached via VNet Peering, VPN, or ExpressRoute. It only works from inside the VM.
