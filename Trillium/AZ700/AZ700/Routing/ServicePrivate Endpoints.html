Service Endpoint [Regional [Public IP | VNet-Only | Free]
> Private Endpoint [Hybrid / Resource-Specific | Private IP | On-Premises Access | 
 
IF Multiple Caveats:

  • Data Exfiltration: Use Private Endpoint to lock traffic to a specific resource instance (e.g., mystorage123 ) instead of the entire service.

  • Hybrid Connectivity: If the scenario requires access via VPN or ExpressRoute, the cliff is Private Endpoint.

  • DNS: If a resource cannot resolve the FQDN to a Private IP, ensure a Private DNS Zone is linked to the VNet.
