Gateways

Top-view decisions
 
SUBNET (Granular) 

  • NAT Gateway IF SNAT Port Exhaustion (≤ 64k ports/IP) [Static (Azure) Outbound IP < 3rd party Whitelist ]

  • UDR (Static) IF  Force Tunnel (Gateway ←→ On-Prem) through NVA/Firewall. 

  • Private Link IF  PaaS [Storage | SQL | Keyvault] with Zero Public IP .

    +Addon: Azure Firewall [PaaS Traffic monitoring / blocking] 

  • NSG/ASG IF  Filter traffic between VMs/Subnets.

VNET (Single Region)

  • VNet Peering default (Min. cost/latency between vnets)

  • Standard Load Balancer* IF L4  [High-throughput (Gb/s) | non-HTTP |  internal traffic]  
    *IF no gateway: Services High Availability (all) ports + outbound rules

  • App Gateway (WAF) IF L7. [SSL Offload | Cookie-affinity | URL-path routing]

 
HYBRID (Cross-Prem)

  • VPN Gateway IF Encryption over (public) Internet

  • ExpressRoute IF Private [Predictable Performance/SLA]

 
Global

  • vWAN IF Managed (Full transitive routing ≤ 50 vnets}|  > 50 VNets | Branch-to-Branch (Any-to-Any)

    +Addon: ExpressRoute [Intercontinental circuits]

  • Front Door IF L7 (HTTP+S) [ [Instant Failover (<10s) |  Edge Caching (CDN) | WAF at the PoP]

    +Addon: Private Link [Secure edge | No Public Internet footprint]

  • Traffic Manager(DNS) IF L4 (Non-HTTP | DNS) Global Routing [Legacy|Gaming| VPN endpoints).

 
🚨 Exam Logic Traps (2026 Fidelity)

  • Failover Speed: Front Door uses Anycast and health probes for near-instant failover (<10s). Traffic Manager is at the mercy of DNS TTL caching, which can delay failover for minutes.

  • Source IP Visibility: Because Front Door is a proxy, your backend sees the Front Door IP, not the client (unless you check the X-Forwarded-For header). Traffic Manager allows the backend to see the original Client IP directly.

  • The "Legacy" Trigger: If the question mentions "Gaming platform" or "Custom TCP protocol," Front Door is a distractor—the answer is Traffic Manager.
