🎯 ADDITIONAL 2026 KILL-SWITCHES

  1. Admin Rule Action: "Always Allow" in AVNM is a final "Allow" that terminates all further NSG evaluation.

  2. Firewall Rule Order: DNAT > Network > Application. A Network Rule match kills the Application Rule check.

  3. DNS Proxy: Required on Azure Firewall to use FQDNs in Network Rule

🎯 2026 KILL-SWITCH TRIGGERS

  • Default Outbound: New 2026 VNets have Zero Default Outbound Access; requires NAT Gateway or Azure Firewall.

  • Service Tags: IP-based filtering for Azure Services in Network Rules or NSGs.

  • FQDN Tags: Pre-defined category filtering (e.g., WindowsUpdate) in Application Rules.

  • WAF Custom Priority: Custom rules (1-100) always process before Managed Rule Sets.
