THE TOOLKIT: ROUTING PRIORITY (LONG-MATCH LIKELY) 
Azure routing doesn't care about "security" priorities; it cares about the Longest Prefix Match first. If prefixes are identical, the following hierarchy applies: 

  • Priority 1: User-Defined Routes (UDR): Your manual overrides.

  • Priority 2: BGP Routes: Learned via ExpressRoute or VPN Gateway.

  • Priority 3: System Routes: The default "Virtual Network," "Internet," and "None" routes
