🛡️ THE UNIFIED AZ-700 ARCHITECT’S SYLLABUS
 
1. THE VIRTUAL FOUNDATION (VNETS & SUBNETS)

  • The Subnet Divas (Solo Only):

    • GatewaySubnet (VPN/ER), AzureFirewallSubnet (FW), AzureBastionSubnet (Bastion), RouteServerSubnet (BGP).

    • 💡 SURGICAL TIP: Never put a VM or a Basic Load Balancer in these. It will break the deployment.

  • The 5-IP Reservation: Azure reserves .0 through .3 and .255 .

    • 💡 SURGICAL TIP: If an exam question asks if a /29 (8 IPs) can hold 4 VMs, the answer is No (

      ).

  • The Platform IP (168.63.129.16): Used for Health Probes, DNS, and DHCP.

    • 💡 SURGICAL TIP: If your Load Balancer shows "Healthy" but traffic fails, check if an NSG is blocking this IP.

 
2. ARCHITECTURAL DECISION MATRIX (CONNECTIVITY)
 

  • 💡 SURGICAL TIP: For "Minimize Administrative Effort," always pick the Managed Service (vWAN, NAT Gateway, Firewall Manager).

 
3. HYBRID CONNECTIVITY & SKU GATES

  • VPN SKU Hard-Stops:

    • Basic: No BGP, No Active-Active, Static Only.

    • VpnGw1+: Yes BGP, Yes Active-Active, Dynamic/Route-based.

  • Routing Logic: UDR > BGP > System.

    • 💡 SURGICAL TIP: Use a UDR to force traffic to a Firewall (Next Hop: Virtual Appliance).

  • BGP Coexistence: The Azure Gateway ASN must be 65515.

 
4. P2S IDENTITY & PROTOCOL MATCHING
 

  • 💡 SURGICAL TIP: If the user is on a Mac and needs Azure AD auth, you must use OpenVPN.

 
5. SECURITY & WAF LOGIC

  • WAF (L7): Only on App Gateway or Front Door. Use for SQLi/XSS.

  • Firewall (Premium): Use for IDPS, TLS Inspection, and FQDN filtering.

  • 💡 SURGICAL TIP: Custom WAF Rules (Priority 1-100) always run BEFORE Managed Rules (OWASP).

 
6. GLOBAL ROUTING & SNAT MATH

  • Routing Equation: If (Region - Fastest) <= Threshold 

  • Use Weight.

  • SNAT Port Allocation: 1-50 VMs = 1,024 ports.

    • 💡 SURGICAL TIP: For 100 VMs, the allocation drops to 512 ports each (Rule of Halves).

 
7. DNS & MONITORING (THE TROUBLESHOOTER)

  • DNS Private Resolver: The "Bridge" for Hybrid name resolution (On-prem to Private Endpoints).

  • Next Hop: Troubleshoot UDR/Routes.

  • IP Flow Verify: Troubleshoot NSG/ASG (Is the port blocked?).

  • VPN Troubleshoot: Check IKEDiagnosticLog for Phase 1/2 negotiation failures.
