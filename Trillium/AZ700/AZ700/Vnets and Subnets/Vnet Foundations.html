🧱 PIXEL-TRUTH (MS-LEARN HARD-LOCKS)

  • Subnet Reservations: You cannot assign the first four or the last IP of any subnet. This is a non-negotiable Azure platform constraint.

  • 168.63.129.16: This is a virtual public IP used across all regions. It is essential for Load Balancer Health Probes. Blocking it in an NSG will cause health probes to fail and take the backend offline.

  • ASN 65515: If using a route-based VPN for coexistence, the gateway uses this specific ASN to manage the path selection between VPN and ExpressRoute.

  • ASN 12076: Required when configuring BGP for ExpressRoute circuits (Private or Microsoft Peering).
