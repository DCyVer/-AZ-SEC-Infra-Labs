Subnet Delegation

SUBNET DELEGATION: THE "SNOBS" (V5.1.17)
Delegation allows a specific PaaS service to "claim" a subnet, injecting its own network interfaces and enforcing its own configuration rules. This prevents other resource types from co-existing in that space. 
 
DEDICATED INFRASTRUCTURE SUBNETS (V5.2.5)
 

  • UDR Exception (GW/AppGW): UDRs are supported ONLY IF the 0.0.0.0/0 route has a Next Hop of Internet. Any other hop (NVA/Firewall) will break the management plane.

  • Forced Tunneling (Firewall): If you route all traffic to an on-premise NVA, you must deploy an additional AzureFirewallManagementSubnet for the firewall’s own control traffic.

  • Infrastructure Ports (AppGW): The 65200-65535 range is mandatory for Azure infrastructure health monitoring; blocking this in an NSG triggers gateway failure.

  • Management IP (Firewall): Azure Firewall always takes a private IP for its own management traffic within the subnet, separate from its operational IPs.

 

 

. SUBNET DELEGATION (PAAS INJECTION)
These subnets are Dedicated by name to Azure infrastructure services. They do not use “Delegation Strings.”
